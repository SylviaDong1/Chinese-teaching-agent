## V3 配对与“了”多轮抽人迭代

检查日期：2026-09-25
课堂实际效果：**待试用**

### 用户反馈与修改原因

- 原 Memory 翻牌需要记忆编号，未直接呈现“季节—活动”的分类关系；课堂需要改为教师可稳定点选、学生可口头判断的固定上下两排。
- 原“了”任务只完成一道题，个人参与和语义角度不足；课堂需要连续4轮、4位不同学生，并由教师判断口头答案。

### 实现内容

- 配对任务上排固定为春天、夏天、秋天、冬天；下排固定使用放风筝、游泳、看红叶、滑雪四项活动，并只在创建新任务时洗牌。若随机结果四组全部上下对齐，会自动轮换一次下排顺序。
- 同一配对任务中的卡片位置不再变化。选错后保留两张选中卡并显示“再想一想”；教师可直接改选。选对后两张卡原位锁定并显示勾号，四组完成后才出现继续按钮。
- 配对说明明确采用“根据本题图片配对”，避免把现实生活中可能成立的其他季节活动搭配一概判断为错误。
- “了”挑战改为4轮状态机：抽取学生、展示情境、学生口头回答、教师判断、显示简短反馈、抽下一位。只有处于对应阶段的按钮才能推进，重复点击不会跳轮。
- 4轮从7个语义类别中抽取4个不同类别。题库覆盖天气、季节、自然、人的感受、穿着生活、时间、否定变化，每类维护2—3个简短情境，并包含关键词、参考答案和可接受的其他表达。
- 每轮使用现有22人学号池，并排除本次4轮已经出现的学号。“再想一想”和“查看参考答案”都保留当前学生与当前题目；参考表达只在教师判定正确后或教师主动点击时显示。
- Agent在抽取结束后播报当前轮次、学号和问题；不会提前播报参考答案。
