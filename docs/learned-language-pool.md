# 第1—9课已学语言池

> 用途：本文件是“AI 中文课堂助教”V1 的语言范围参考。后续课堂互动应优先复现第1—8课熟词、熟句，并只把第9课内容作为本课新语言使用。
>
> 教材来源：《新实用汉语课本（第3版）课本1》。本次核对范围为第1课《你最近怎么样》至第9课《天气凉快了》。下列词汇以课堂高频和可复用项为主，不等同于逐条抄录教材生词表；第9课主课文生词则单独完整列出。教材 PDF 为扫描版，内容依据目录、课文、生词表、核心句和语法页逐页核对。

## V1.1 使用原则：教材语言是底座，不是围墙

- 第1—8课熟词熟句仍是课堂互动的主要语言来源，第9课语言仍是教学核心。
- 围绕“四季、天气、季节活动”，可以加入极少量能由图片或 emoji 直接理解的扩展词。
- V1.1 允许的视觉扩展词为：`🌸 花`、`🍉 西瓜`。它们只作情境提示，不承担新语法讲解，也不要求所有学生产出。
- 每个画面最多出现一个这类扩展词；不继续扩充季节文化词表。
- Agent 的提问、反馈和学生目标句仍优先使用本文件已经列出的语言。

## 使用标记

- **熟词 / 熟句**：第1—8课已经出现，可直接用于教师指令、Agent 提问和学生作答。
- **第9课新学**：可以在本课中呈现、练习和反馈。
- **范围外新词**：第1—9课未作为主要教学内容出现。确需使用时，应显式标注并给出图片或极简解释。
- 专名“南京、南京大学”属于真实课堂情境所需的**范围外专名**，可直接配地图、校名或图片使用，不把它们当作本课词汇考查。

## 1. 第1—8课已学语言

### 第1课《你最近怎么样》

**核心词汇**

你、我、他、好、叫、名字、姓、请、请问、什么、认识、很、高兴、也、在、吗、进、坐、谢谢、最近、怎么样、呢、忙、不、太。

**主要句型与语法**

- 用“吗”的是非问句：`你忙吗？`
- 形容词谓语句：`我很好。`、`我不太忙。`
- “也”的位置：主语 + 也 + 动词/形容词，如 `他也很好。`
- 省略问句“……呢？”：`我很好。你呢？`
- 基本语序：主语 + 谓语（+ 宾语）。
- 熟句：`你最近怎么样？`、`你叫什么名字？`、`我姓……，叫……。`

### 第2课《你是哪国人》

**核心词汇**

是、不是、这、那、哪、国、人、中国、外国、北京、上海、老师、学生、朋友、妈妈、谁（在后续课继续使用）、饺子、包子、和、都、好吃、贵姓、您。

**主要句型与语法**

- “是”字句及否定：`这是……。`、`这不是……。`
- 疑问代词“什么、哪”：`这是什么？`、`你是哪国人？`
- 连词“和”：`包子和饺子。`
- “都”的位置：主语/并列成分 + 都 + 谓语，如 `包子和饺子都很好吃。`
- 熟句：`这是我的朋友。`、`你是哪国人？`、`我是……人。`

### 第3课《你们家有几口人》

**核心词汇**

家、有、没有、几、口、人、一共、爸爸、妈妈、哥哥、姐姐、弟弟、妹妹、儿子、女儿、照片、漂亮、工作、做、今年、岁、晚上、还、英语课、小狗。

**主要句型与语法**

- “有”字句及否定：`我们家有六口人。`、`我没有妹妹。`
- 表领属的定语：`我们的照片`、`我的家`。
- 数量词作定语：`一张照片`、`六口人`、`一个学生`。
- 疑问代词“谁、几”：`他是谁？`、`你女儿几岁？`
- “还”表示补充、追加：`晚上他还有英语课。`
- 熟句：`你们家有几口人？`、`这张照片真漂亮！`

### 第4课《你明天几点有课》

**核心词汇**

明天、今天、上午、中午、下午、晚上、点、分、半、差、课、有时间、一起、练习、口语、语法、听力、阅读、电影、看、累、班、学生、多少。

**主要句型与语法**

- 11—100 的称数法。
- 钟点读法：`八点半`、`差五分七点`。
- 时间词语作状语：`我明天上午八点半有语法课。`
- 正反疑问句：`你看不看电影？`、`你累不累？`
- 动词谓语句：`我们一起练习口语吧。`
- 用“呢”构成省略问句。
- 熟句：`现在几点？`、`你明天晚上有没有时间？`、`我们班一共有多少人？`

### 第5课《祝你生日快乐》

**核心词汇**

年、月、日、号、星期、生日、出生、今年、多大、岁、蛋糕、送、礼物、教、汉语、写、汉字、祝、快乐、介绍、一下、就是、来、咱们。

**主要句型与语法**

- 年、月、日和星期的读法：`十月二十七号`、`星期日`。
- 名词谓语句：`今天星期三。`、`他今年二十七岁。`
- 双宾语动词谓语句：`我送他一个生日蛋糕。`、`他们教我说汉语、写汉字。`
- “就”表示强调：`他就是我哥哥。`
- 疑问语调句。
- 已接触的句子成分：主语、谓语、宾语、定语、状语。
- 熟句：`今天几号？`、`祝你生日快乐！`、`我来介绍一下。`

### 第6课《图书馆在食堂北边》

**核心词汇**

学校、校门、食堂、图书馆、办公楼、宿舍、银行、饭馆、地方、里边、外边、左边、右边、上边、下边、前边、后边、旁边、对面、东边、西边、南边、北边、在、有、是、跟、给、等、一下。

**主要句型与语法**

- 方位词：`里边、外边、前边、后边、旁边、对面、东边、西边、南边、北边`等。
- “在”字句表示位置：`食堂在校门右边。`
- “有”表示存在：`学校里边有银行吗？`
- “是”表示判断：`食堂旁边是办公楼。`
- 介词结构“跟/给 + 代词或名词”：`你跟我来。`、`我给你介绍一下。`
- 用“……，好吗？”“……，对吗？”提问。
- 熟句：`……在哪儿？`、`……在……旁边。`、`……里边有……吗？`

### 第7课《苹果多少钱一斤》

**核心词汇**

买、卖、苹果、草莓、水果、斤、公斤、多少钱、钱、块、毛、百、千、贵、便宜、一点儿、想、可以、给、找、再、试、件、衬衫、大号、颜色、穿、衣服。

**主要句型与语法**

- 百、千的称数法。
- 能愿动词“想、可以”：`我想买点儿苹果。`、`可以刷卡吗？`
- 双宾语动词谓语句“给、问、找”：`您给我六十，我找您八块。`
- 疑问代词“怎么”：`这个汉语怎么说？`
- 熟句：`苹果多少钱一斤？`、`便宜点儿吧。`、`这件衬衫多少钱？`

### 第8课《我全身都不舒服》

**核心词汇**

快、起床、床、每、运动、为什么、可是、头、疼、对不起、舒服、没关系、嗓子、有（一）点儿、应该、医院、看病、身体、睡觉、能、上课、还是、天气、冷、穿、衣服、全身、量、体温、大夫、度、发炎、打针、不用、水、休息、中药。

**主要句型与语法**

- 主谓谓语句：`我头疼。`、`他全身都不舒服。`、`今天天气很冷。`
- 选择疑问句：`现在去还是下午去？`
- 连动句表示目的：`去医院看病。`
- 能愿动词“应该、要、能”：`你应该去医院看病。`、`你要多休息。`、`明天还不能上课。`
- 介词结构“在 + 代词/名词”：`你在这儿等一下。`
- 熟句：`你哪儿不舒服？`、`天气很冷。`、`多穿点儿衣服。`

### 第1—8课中与第9课衔接最紧密的熟语言

- **问候和问情况**：`……怎么样？`（第1课）
- **形容词谓语**：`很 + 形容词`、`不太 + 形容词`（第1课）
- **并列和共同情况**：`和`、`都`、`也`（第1—2课）
- **描述性词语**：`漂亮`（第3课）、`舒服`（第8课）
- **时间和日期**：`现在、今天、明天、上午/下午/晚上、几点`，以及 `年、月、日/号、星期`（第4—5课）
- **位置与场景**：`在`、`有`、`学校、校门、里边、外边、旁边`等（第6课）
- **意愿和许可**：`想、可以`（第7课）
- **天气基础**：`天气、冷`（第8课）
- **程度和否定**：`很、太、不、不太、有点儿、一点儿`（第1、7、8课）

## 2. 第9课新增语言

### 第9课主课文生词

**季节、天气与活动**

秋天、了、凉快、空气、最、季节、热、春天、暖和、刮风、风、家乡、树、夏天、冬天、下雨、雨、下雪、雪、游泳、滑雪、会、以前。

**出行与交通**

（飞）机票、飞机、票、坐、博物馆、展览、时候、车、开车、开、驾照、打车、路上、可能、堵车、堵、慢、地铁、公共汽车、公共、汽车、路、换、线、饿、天安门、苹果园。

### 第9课补充词语

教材“补充词语”包括：火车、火车站、船、机场、骑、自行车、走路、滑冰、篮球、排球、踢、足球、城里、美术馆、参观、公园、售票员、师傅。

这些词属于本课扩展，不是天气游戏的必要输入。V1 除非要呈现交通方式，否则不使用。

### 第9课核心句

- `现在是秋天了。`
- `天气凉快了。`
- `今天我也有时间了。`
- `现在几点了？`
- `今天天气真好啊！`
- `你最喜欢什么季节？`
- `咱们打车去吧。`
- `打车去可能很慢。`
- `咱们坐地铁和公共汽车，怎么样？`
- `飞机票太贵了。`
- `我会开车。可是我没有中国驾照，在这儿不能开。`

### 第9课新增句型与语法

1. **句尾“了”表示情况发生变化或出现新情况**
   - `天气凉快了。`（以前不凉快/很热）
   - `树都绿了。`（以前不绿）
   - `现在是秋天了。`（以前不是秋天）
   - `今天我也有时间了。`（以前没有时间）
   - 判断是否发生变化可问：`天气凉快了吗？`
   - 没有发生变化时，按谓语类型用 `没有……` 或 `不是……`，如 `天气没有凉快。`、`现在不是秋天。`

2. **连动句表示方式**
   - 结构：主语 + 交通/方式动词 + 主要动作。
   - `他每天坐公共汽车回家。`
   - `我们开车去王府井。`

3. **能愿动词“会、可能”**
   - `会 + 动词`表示通过学习掌握的能力：`我会游泳。`、`你会不会滑雪？`
   - 常用回答：`会。`、`不会。`、`会一点儿。`
   - `可能 + 动词/形容词`表示不确定的可能：`可能下雨。`、`打车去可能很慢。`

4. **“……，怎么样？”征求意见或提出建议**
   - `咱们坐地铁和公共汽车，怎么样？`
   - 肯定回应可用：`好啊。`、`好。`、`好的。`、`好吧。`
   - 否定回应可用：`对不起，……`并说明理由。

5. **“最 + 形容词/动词”表示最高程度**
   - `最好`、`最贵`、`最漂亮`、`最喜欢`。
   - `你最喜欢什么季节？`

## 3. V1 游戏可使用语言

### A. 可直接使用的熟词、熟句

这些语言在第1—8课已经学过，适合做按钮、教师提示、Agent 反馈和学生回答支架：

- **课堂互动**：请、看、听、说、问、回答、再、试、一下、一起、好吗、对吗、谢谢、很好、对不起、没关系。
- **问句框架**：`……吗？`、`……呢？`、`……怎么样？`、`什么？`、`哪儿？`、`为什么？`、`谁？`、`几？`、`多少？`
- **判断与描述**：是、不是、有、没有、很、不、太、不太、也、都、真。
- **时间**：现在、今天、明天、以前（第9课新学）、上午、下午、晚上、年、月、日/号、星期。
- **天气相关熟词**：天气、冷、舒服、漂亮。
- **熟句框架**：`今天天气怎么样？`、`今天天气很冷。`、`……很舒服。`、`……真漂亮！`

### B. 本课可以重点练习的新语言

- **词汇**：春天、夏天、秋天、冬天、热、凉快、暖和、刮风、下雨、下雪、游泳、滑雪、最、喜欢、会、以前、了。
- **目标句型**：
  - `现在天气怎么样？`
  - `天气凉快了。`
  - `现在是秋天了。`
  - `你最喜欢什么季节？`
  - `我最喜欢秋天。`
  - `秋天很凉快。`
  - `秋天不冷也不热，很舒服。`
  - `你会不会游泳/滑雪？`
  - `我会。` / `我不会。` / `我会一点儿。`
  - `我们去游泳/滑雪，怎么样？`

### D. V1 推荐反馈语

尽量使用短、熟、可听懂的反馈：

- 正确：`对！`、`很好！`、`说得很好！`、`对，现在天气凉快了。`
- 再试：`再试一下。`、`以前很热。现在还热吗？`、`想一想：“了”。`
- 强调变化：`以前很热，现在凉快了。以前和现在不一样。`

其中“不一样”里的“一样”是**范围外新词**。若使用，应配“以前 → 现在”的视觉对比；或者改用范围内表达：`以前很热。现在还热吗？`

### E. V1 应避免或谨慎使用的语言

- 避免把第9课交通部分（驾照、堵车、换线等）塞进天气与季节游戏。
- 避免长段语法解释。课堂界面优先显示“以前 → 现在”和一组短句。
- 避免未经标注的新形容词和季节活动词，如“潮湿、干燥、赏花、枫叶、温度下降”等。
- “南京、南京大学”只作为真实情境专名；不要围绕它们增加大量城市文化新词。
- “投票、挑战、Agent/助教”是界面操作词，不要求学生学习或产出。若显示中文，配图标或按钮状态即可。

## 后续设计约束

1. 学生主要输出应限制在一到两个短句。
2. 每个画面最多突出一个新句型；解释尽量通过对比、图片和教师口头组织完成。
3. 优先使用“熟词 + 第9课新结构”的组合，例如：`天气（熟） + 凉快（新） + 了（新）`。
4. Agent 反馈先肯定意思，再把注意力引向目标形式；例如学生说“天气很凉快”时，不判为完全错误，而提示“以前很热。现在还热吗？想一想：‘了’。”
5. 未列入本文件但确需出现的词，应在设计稿和界面文案中标记为**范围外新词**，并提供图片、图标或极简解释。
