# Chinese-teaching-agent

面向初级汉语学习者的“AI 中文课堂助教”原型。

## V1.1：南京天气变了

这是一个约 8—10 分钟的课堂互动游戏。课堂主线从四季、天气和活动自然走到南京十月的变化。老师主要点击按钮控制节奏，学生现场口头回答、投票并挑战 Agent 助教；文字输入只是折叠的备用入口。

支持的浏览器会显示中文朗读和语音回答功能；不支持语音识别时，老师仍可用大按钮走完整个流程。

### 最简单的打开方式

直接双击 `dist/index.html`，用浏览器打开。

### 使用本地服务器（推荐）

在项目目录运行：

```bash
python3 -m http.server 8000 --directory dist
```

然后访问：<http://localhost:8000>

页面不需要安装依赖，也不需要数据库或登录。
