# Chinese-teaching-agent

面向初级汉语学习者的“AI 中文课堂助教”原型。

## 师—生—机协同教学融合版

这是一个由老师控制节奏、学生开口参与、Agent 提供题目与支架的课堂工具。首页提供三个入口：1—2分钟的快问快答、支持20+学生的全班投票，以及课末8—10分钟的“四季大冒险”综合复习游戏。

四季大冒险保留地图、四队、棋子、骰子和任务卡。棋子位置负责游戏感；课堂进度由10次核心互动控制，达到10次后开启 Final Challenge。独立全班投票不计入游戏进度，冒险内部也不再自动插入大型投票。

需要口头回答的任务以学生现场开口为主。学生说完后点击“已完成”，Agent 才显示参考表达。语音识别只是可选入口，不支持时仍可只靠按钮走完整个流程。

浏览器支持时，可以选择中文声音、调整语速、播放 Agent 关键句，并尝试语音回答。声音设置会保存在当前浏览器中。

### 最简单的打开方式

直接双击 `dist/index.html`，用浏览器打开。

### 使用本地服务器（推荐）

在项目目录运行：

```bash
python3 -m http.server 8000 --directory dist
```

然后访问：<http://localhost:8000>

页面不需要安装依赖，也不需要数据库、登录或联网房间。

### 教师控制台

1. “快问快答”从季节、天气、活动题库随机出题，老师决定提示、参考表达和下一题何时出现。
2. “全班投票”按25票尺度逐票更新，支持撤销、重置、结果总结和简短追问。
3. “四季大冒险”由四队轮流掷骰子并完成地图任务；进度达到10 / 10后进入 Final Challenge。

### 课堂玩法

- 👀 看图说中文：根据季节、天气和活动场景口头表达。
- 🎭 动作猜词：每次随机进行3轮，从15个四季、天气和活动动作中抽取；学生先猜词或季节，再说完整句。
- 💬 两人对话：学生 A、B 根据角色卡完成很短的问答。
- 🤖 找出 Agent 的问题：全班判断表达是否还能更好，再帮助 Agent 加上表示变化的“了”。
- 💣 偏误分析 / 句子诊断：17道题覆盖“了”的漏用、误用、位置问题，以及语法问题、语境不自然和“正确但可更符合变化语境”。
- ⏱️ 快速挑战：10 秒轻量计时，时间到不扣分，学生仍可继续回答。
- ⚡ “变了！”挑战：13个变化情境覆盖四季到来、冷暖变化、花开、叶黄、雨雪风、补句和正确表达选择。
- 🎁 幸运格 / 📣 全班快闪：快速移动、提示、再掷一次或一起说一句。

核心任务顺序经过课堂节奏控制：前半程先使用四季、天气、活动，中段进入完整句与表达，后半程出现 Agent 纠错、句子诊断、快速变化和“了”的挑战。骰子不会决定 Final Challenge 的解锁时间。

当前融合版仍是单机大屏原型；投票由大屏点击模拟，没有手机端、账号、数据库或多人联网。

### V3.1 课堂参与增强

- 随机挑战者使用独立维护的22人学号池：`02、03、06—14、16—26`（不含 `01、04、05、15`）。一次冒险中优先抽取未出现过的学生，22人全部抽完后才开启新池。
- 看图、动作和纠错任务可由教师选择是否抽取个人挑战者；每类每局只提示一次。独立的“了”变化挑战固定进行4轮，每轮从22人学号池中抽取一位不同学生。对话、计时、配对和幸运事件继续以小组或全班参与为主。
- 任务引擎会在10次核心互动中动态补齐天气、活动、表达、变化、纠错和 Memory；Memory 只触发一次。配对卡固定为上排“春夏秋冬”、下排四项活动，下排只在新任务开始时洗牌；正确配对保留并锁定，错误配对原位重选，四组完成后再由教师继续。
- Final Challenge 改为五类知识选题板：季节、天气、活动、“了”、找错误。每类有一至三星，四队依次自主选择，教师使用“正确 / 给提示 / 再想想”控制流程。
- 所有操作仍由教师在单一大屏完成，不包含学生端、扫码、登录、排行榜或自动语音判分。
